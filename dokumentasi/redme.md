# Dokumentasi Pengujian Aplikasi Pemesanan Kantin Kampus

## Tujuan Pengujian
Pengujian dilakukan untuk memastikan aplikasi pemesanan kantin kampus berjalan sesuai dengan ketentuan.

## Daftar Pengujian

| Kode | Pengujian | Hasil |
|---|---|---|
| U01 | Menampilkan daftar menu | Belum diuji |
| U02 | Pencarian menu yang tersedia | Belum diuji |
| U03 | Pencarian menu yang tidak ditemukan | Belum diuji |
| U04 | Validasi jumlah pesanan kosong atau tidak valid | Belum diuji |
| U05 | Menolak kode menu yang tidak dikenal | Belum diuji |
| U06 | Membatasi jumlah pesanan maksimal 10 | Belum diuji |
| U07 | Menambahkan menu yang sama ke keranjang | Belum diuji |
| U08 | Mempertahankan keranjang saat halaman diperbarui | Belum diuji |
| U09 | Menghitung subtotal, diskon, dan total pembayaran | Belum diuji |
| U10 | Menghapus item dan mengosongkan keranjang | Belum diuji |
| U11 | Menyimpan kategori favorit menggunakan cookie | Belum diuji |

## Kesimpulan
Hasil pengujian akan dicatat setelah setiap fitur dijalankan. Fitur dinyatakan berhasil apabila memberikan hasil sesuai dengan ketentuan aplikasi.
